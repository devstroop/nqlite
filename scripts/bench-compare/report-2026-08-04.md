# Cross-DB benchmark — first run (2026-08-04)

Host: Raspberry Pi (arm64), Python 3.13 venv, sqlite-vec / lancedb / chromadb
drivers installed. Corpus: 1000 rows, dim-8 float vectors, 8-word vocabulary,
xorshift64* seed 42 (byte-identical to `nql-bench`). kNN = 50 queries, k = 10.
All times in milliseconds; lower is better. Only same-shape cells compare.

| db        | ingest(ms) | knn(ms) | bm25(ms) | hybrid(ms) |
|-----------|-----------:|--------:|---------:|-----------:|
| nqlite    |       3.74 |  443.83 |   608.23 |    1260.78 |
| sqlite-vec|      22.21 |    3.43 |  n/a     |     n/a    |
| lancedb   |       4.17 |  158.67 |  n/a     |     n/a    |
| chroma    |     200.21 |   38.85 |  n/a     |     n/a    |

## How to read this

- **ingest** — nqlite (3.74ms) beats sqlite-vec (22.21ms) and chroma
  (200.21ms); lancedb (4.17ms) is comparable. nqlite inserts are a single
  in-memory plan with no per-row IPC.
- **knn** — nqlite brute-force (443.83ms / 50 queries ≈ 8.9ms per query over
  1000 dim-8 records) is expectedly slower than indexed stores: sqlite-vec
  (3.43ms), chroma (38.85ms), lancedb (158.67ms). nqlite's default index is
  exact brute-force by design (determinism); HNSW is feature-gated and will
  close part of this gap when enabled.
- **bm25 / hybrid** — n/a for competitors (no lexical or fused operator).
  nqlite is the only store with lexical + vector + fusion in one query.

## What this means (honest)

- nqlite is **not the fastest vector index** — it is the only embedded store
  that does records + graph + vectors + lexical + hybrid under one
  deterministic transaction. The kNN gap is the price of exactness, and HNSW
  (feature-gated) is the knob.
- These numbers are **throughput/latency only**; nqlite's determinism means
  output is identical for identical input, which none of these stores
  guarantee end to end.

## Reproduce

```sh
python3 -m venv /tmp/bench-venv
/tmp/bench-venv/bin/pip install sqlite-vec lancedb chromadb
/tmp/bench-venv/bin/python3 scripts/bench-compare/bench.py --rows 1000 --knn 50
```
